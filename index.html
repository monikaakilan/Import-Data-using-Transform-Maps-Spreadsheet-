What is a Transform Map?

Understand the basic idea before importing your spreadsheet.

📥

Import Data

Bring data from an external spreadsheet or file into the target platform using an import process.

🔄

Transform

Convert incoming values into the format required by the destination table or application.

🗺️

Map Fields

Connect spreadsheet columns with the corresponding fields in the target database.
